# 설계 노트: 주도테마 감지 로직 최적화 (V23.7.4)

## 1. 문제 정의
- **동점자 처리 취약성**: `list.index()` 사용 시 0점 테마들이 모두 상위권(rank=0)으로 오판정되어 예열 테마 감지가 불가능함.
- **모호한 순위 기준**: 전체 테마(140+) 기준의 절대 비율 판정은 상위 Top-k 20 종목 기반의 실제 경쟁 풀을 제대로 반영하지 못함.

## 2. 주요 변경 사항 (L3)

### 2.1. Top-k 기반 상대 랭킹 (Relative Ranking)
- **전제**: NCQ 엔진은 이미 거래대금 상위 종목을 기반으로 테마를 집계함. 따라서 집계된 테마 풀(`theme_map`) 자체가 이미 정제된 '유효 경쟁 풀'임.
- **수학적 개선**: `sum(1 for h in values if h > current)` 방식을 통해 동점자가 있어도 정확한 상대적 순위 도출.
- **구간 재정의**:
  - **🔥 Leader (주도)**: 경쟁 풀 내 상위 20%
  - **🌱 Preheat (예열)**: 경쟁 풀 내 중간 40% ~ 80% 구간 (상승 관성 동반 필수)

### 2.2. 감도 및 UI 최적화
- **자금 이동 (`_FLOW_THRESHOLD = 5`)**: 실시간 순환매 포착력 강화.
- **노출 제한**: 레이더 최대 2개 항목 고정으로 사이드바 UI 레이아웃 보호.
- **카드형 컨테이너**: `Qt.WA_StyledBackground` 기반의 독립적 정보 박스 구조 확립.

## 3. 구현 세부 사항
- `RankingManager.aggregate_theme_flow()`: Top-k 상대 분포 로직 적용.
- `ThemeFlowWidget`: `InfoBox` 스타일링 및 카드형 렌더링 담당.
