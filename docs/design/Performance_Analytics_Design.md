# 퍼포먼스 분석 및 수익률 설계 (Performance Analytics Design)

## 1. 개요
본 문서는 NoCodeQuant 시스템의 수익률 계산, 승률 추적, 그리고 최대 낙폭(MDD) 산출 로직에 대한 설계 가이드를 제공합니다.

---

## 2. 핵심 지표 산출 로직

### 2.1 실시간PnL (Live PnL)
- **공식**: `(현재가 - 평균단가) * 보유수량`
- **반영**: `process_market_data` 루프 내에서 매 틱(Tick)마다 계산되어 `pos_widget`에 반영됩니다.

### 2.2 누적 수익률 (Cumulative P&L)
- **공식**: `이전 누적 수익 + 당일 실현 손익`
- **저장**: 메인 대시보드의 `cumulative_pnl` 변수에 유지되며, 차트 하단에 시각화됩니다.

### 2.3 승률 (Win Rate)
- **공식**: `(익절 횟수 / 전체 매매 횟수) * 100`
- **기준**: 수수료와 슬리피지를 제외한 순수익이 0보다 큰 경우를 승리로 간주합니다.

### 2.4 최대 낙폭 (MDD, Maximum Drawdown)
- **공식**: `현재 누적 수익 - 역대 최고 수익점(High-Water Mark)`
- **추적**: `mdd` 변수에 실시간으로 최소값을 갱신하며 기록합니다.

---

## 3. UI 시각화 규칙

### 3.1 색상 규칙
- **수익(Profit)**: `#f44336` (Red) - 한국 시장 관습에 따라 상승/수익은 빨간색으로 표시합니다.
- **손실(Loss)**: `#2196f3` (Blue) - 하락/손실은 파란색으로 표시합니다.
- **중립(Neutral)**: `#eeeeee` (White/Silver)

### 3.2 차트 업데이트
- PnL 변화가 감지될 때마다 `mini_chart`의 하단 영역에 히스토리 데이터를 추가합니다.
- 데이터 포인트가 일정 수(200개)를 넘으면 가장 오래된 데이터부터 삭제하여 메모리를 관리합니다.

---

## 4. 데이터 영속성 (Persistence)
- 당일의 최종 성적(Final PnL, Win Rate, MDD)은 세션 종료 시 또는 프로그램 종료 시 `settings.json`에 스냅샷 형태로 저장되어 다음 기동 시 참조될 수 있습니다. (향후 DB 연동 예정)
