# Institutional Grade Upgrade Plan: NoCodeQuant V13

본 문서는 노코드퀀트를 "단순 전략 도구"에서 **"기관급 운용 OS"**로 진화시키기 위한 내일의 핵심 작업 유지를 위해 작성되었습니다.

## 1. 데이터 영속성 및 포렌식 (SQLite 3 WAL)
현재 메모리 중심의 실시간 처리를 파일 기반의 영속성 체계로 전환합니다.
- **`trading_storage.py` 신설**:
    - SQLite3 WAL 모드 설정 (Read/Write 동시성 확보).
    - `signals` 테이블: 모든 틱에 대한 지표 점수 및 신뢰도 스냅샷 저장.
    - `trades` 테이블: 진입, 청산, 손익, 그리고 당시의 전략 설정값 저장.
- **기대 효과**: 프로그램 재시작 시에도 과거 차트와 매매 이력을 100% 복구하여 분석 가능.

## 2. Global Trade ID (GTID) 체계 도입
모든 의사결정의 "생애주기"를 추적하는 고유 식별자를 구현합니다.
- **ID 구조**: `YYYYMMDD-종목코드-SEQ-UUID`
- **구현**:
    - `SignalResult` 클래스에 `gtid` 필드 추가.
    - 진입 주문 시 생성된 ID는 청산 시까지 유지되어 모든 관련 로그(주문, 체결, 에러)와 결합.
- **기대 효과**: 특정 매매에 대한 포렌식 분석 및 머신러닝 학습 데이터 라벨링의 정확도 확보.

## 3. 변동성 적응형 리스크 제어 (Adaptive Risk Execution)
고정된 수치를 넘어 시장 상황에 스스로 적응하는 방어막을 구축합니다.
- **Dynamic Threshold**: `ATR` 또는 정규화된 변동성이 일정 수준 이상일 경우 `ENTRY_THRESHOLD`를 자동으로 상향 조정 (노이즈 구간 회피).
- **Volatility Escape 2.0**: 1초 이내 급변동 감지 시 AI 판단 없이 즉시 시장가 탈출 로직을 엔진 레이어(`engine.py`)에 직접 삽입.
- **기대 효과**: 변동성 장세에서의 불필요한 손절 방지 및 자산 원천 보호.

## 4. 시스템 무결성 및 장애 로그 (`docs/incidents`)
시스템의 모든 비정상 상태를 자산화합니다.
- **`IncidentLogger` 신설**: 런타임 오류(Exception) 발생 시 자동으로 발생 켄텍스트(당시 지표값, 스택 트레이스)를 `docs/incidents/`에 마크다운 파일로 생성.
- **기대 효과**: AI와 사용자가 함께 시스템의 약점을 파악하고 지속적으로 개선하는 워크플로우 확립.
