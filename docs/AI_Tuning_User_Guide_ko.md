# AI 전략 튜닝 사용자 가이드 (AI Tuning User Guide) [V27.0]

본 문서는 NoCodeQuant 시스템의 **AI 전략 진단 및 자율 튜닝 엔진**을 효과적으로 활용하기 위한 공식 매뉴얼입니다. 상위 1% 트레이딩 성과를 위해 시스템이 제공하는 정량적 분석과 제어 기능을 숙지하십시오.

---

## 1. 개요 (Overview)

AI 전략 튜닝 엔진은 현재 운용 중인 전략의 성과(WR, PF, Edge)를 실시간으로 분석하여, 변화하는 시장 환경에 최적화된 파라미터를 제안하고 즉각적으로 적용할 수 있는 기능을 제공합니다.

- **진단(Diagnostic)**: 최근 20~100건의 거래 데이터를 기반으로 전략의 건강도를 점수화합니다.
- **튜닝(Tuning)**: 진단 결과에 따라 RSI 임계값, 트레일링 스탑, 비중 등의 파라미터를 자동 조정합니다.
- **관측성(Observability)**: 현재 어떤 튜닝이 적용되어 있는지 실시간 상태 뱃지로 표시합니다.
- **롤백(Rollback)**: 적용된 튜닝을 클릭 한 번으로 이전 상태로 안전하게 복구합니다.

---

## 2. 전략 진단 카드 읽는 법 (How to Read Diagnostic Cards)

전략 대시보드의 **[AI Tuning]** 탭에서 각 전략의 진단 카드를 확인할 수 있습니다.

### 2.1 진단 점수 및 지표 (Scoring Metrics)
- **WR (Win Rate)**: 승률 (20% 가중치)
- **PF (Profit Factor)**: 수익 손실비 (40% 가중치)
- **Edge Ratio**: 손익비 가속도 (40% 가중치)
- **PnL Analysis**: MFE(최대 수익), MAE(최대 손실), 평균/누적 수익률을 종합 분석합니다.

### 2.2 전략 상태 아이콘
- 🔵 **EXCELLENT**: 전략이 시장 국면에 최적화되어 있습니다. 유지 권장.
- 🟢 **GOOD**: 안정적인 성과를 내고 있습니다.
- 🟠 **MIXED**: 성과 지표가 엇갈리고 있습니다. 세부 튜닝을 검토하십시오.
- 🔴 **WEAK**: 엣지가 소멸되었습니다. 파라미터 대수술이나 전략 교체가 필요합니다.
- 💀 **DISABLE**: 리스크가 과도합니다. 즉시 운용 중단을 고려하십시오.

---

## 3. 자율 튜닝 프로세스 (Tuning Workflow)

### 3.1 [적용하기 ▶] 버튼
AI가 제안하는 구체적인 액션(예: "진입 임계값 강화 권고") 옆의 버튼을 클릭하면 튜닝이 시작됩니다.

### 3.2 포지션 안전 정책 (Safety Policy)
- **포지션 미보유 시**: 파라미터가 `ACTIVE_CONFIG`에 **즉시 적용(APPLIED)**됩니다. 다음 진입부터 변경된 로직으로 작동합니다.
- **포지션 보유 시**: 매매 혼선을 방지하기 위해 **큐잉(QUEUED)** 상태로 대기합니다. 현재 포지션이 청산(Fill)되는 즉시 시스템이 자동으로 파라미터를 업데이트합니다.

---

## 4. 튜닝 상태 관리 (State Management)

전략 카드 상단에 표시되는 **현재 상태 뱃지**를 통해 시스템의 튜닝 현황을 한눈에 파악할 수 있습니다.

| 상태 뱃지 | 의미 | 설명 |
| :--- | :--- | :--- |
| ⚙️ **ORIGINAL** | 기본 설정 | AI 튜닝이 적용되지 않은 초기 설정 상태입니다. |
| 🟡 **QUEUED** | 적용 대기 | 튜닝 명령이 내려졌으나, 포지션 청산 후 적용을 위해 대기 중입니다. |
| 🟢 **TUNED** | 튜닝 운영 | AI 튜닝이 실거래 파라미터에 반영되어 운용 중인 상태입니다. |

### 4.1 [↩ 원복] 기능 (Rollback)
- **대상**: 🟢 **TUNED** 상태인 전략
- **기능**: 적용된 파라미터를 튜닝 수행 이전의 값으로 정밀 복구합니다.
- **용도**: 튜닝 후 예상치 못한 성과 저하가 발생하거나, 수동으로 제어권을 회수하고 싶을 때 사용합니다.

---

## 5. 거버넌스 및 감사 (Governance & Audit)

모든 튜닝 및 롤백 활동은 시스템의 **포렌식(Forensic) 감사 원장**에 영구 기록됩니다.

1. **로그 확인**: 메인 창 하단 로그 세션에서 `[AI Tuning]` 태그가 붙은 메시지를 확인하십시오.
2. **이력 추적**: **포렌식 대시보드**의 `GOVERNANCE_LOG` 이벤트를 통해 수정 전(Before)과 수정 후(After)의 상세 Diff 데이터를 조회할 수 있습니다.

---

## 6. 주의 사항 (Precautions)

- **멱등성(Idempotency)**: 동일한 튜닝을 여러 번 클릭해도 시스템은 중복 적용을 자동으로 차단합니다.
- **유효 기간 (TTL)**: 큐(QUEUED)에 대기 중인 튜닝은 24시간이 경과하면 안전을 위해 자동 폐기됩니다.
- **데이터 부족 시**: 거래 건수가 5건 미만인 전략은 진단 신뢰도가 낮아 `LOW_DATA` 경고와 함께 버튼이 노출되지 않을 수 있습니다.
