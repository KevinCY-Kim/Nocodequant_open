# 📊 전략 엔진 매도(Exit) 로직 분석 보고서

**대상 파일**: `app/ai/strategy.py`  
**버전**: [V22.1] Asymmetric "Full-Spec" Exit Engine

---

## 1. 개요 (Overview)

NoCodeQuant의 매도 로직은 V22.1에 이르러 설계 문서상에만 존재하던 **R-Multiple 기반 비대칭 출구 엔진**을 실제 코드로 완벽하게 이식 완료했습니다. 단순히 시장 상황만이 아니라, 개별 포지션의 수익 가치(`R-Value`)에 따라 트레일링 스탑을 동적으로 조여 수익을 기하급수적으로 보호합니다.

---

## 2. R-Multiple 기반 척도 (The R-Standard) [V22.1 실구현]

모든 출구 판단의 절대적 기준은 **1R(리스크 단위)**입니다.
-   **정의:** `1R = 진입가 - 최초 손절가(initial_sl)`
-   **안전핀 1 (Zero-R Guard):** 초저변동성 종목에서 R값이 0에 수렴하여 배수가 폭주하는 것을 막기 위해, 최소 R값을 `진입가 * 0.5%`로 강제 보장합니다.
-   **계산:** `current_r = (현재가 - 진입가) / R_Value`

---

## 3. 비대칭 매도 4계 (Asymmetric 4-Plans)

### ① 제1계: 무위험 지대 (Free-Ride Zone / BE Switch)
-   **트리거:** 수익이 **2.2R** 에 도달 시 발동.
-   **작동:** 손절선을 `진입가 + (0.2 * R)` 위치로 상향 전진 배치.
-   **의도:** 이때부터 해당 포지션은 '절대 잃지 않는 싸움'이 되며, 심리적 안정을 통해 대세승을 끝까지 추적합니다.

### ② 제2계: 수익 비례 가변 트레일링 (Dynamic Tightening)
수익이 커질수록 트레일링 배수를 타이트하게 조여 수익을 '잠금(Lock)'합니다.

| 수익 구간 | ATR 배수 | 상태 |
| :--- | :---: | :--- |
| **1.5R ~ 2.2R** | **4.5x** | 관찰: 잔파도 허용, 큰 추세 탐색 |
| **2.2R ~ 3.2R** | **3.0x** | 보호: BE 확정 후 안정적 방어 |
| **3.2R ~ 5.2R** | **2.0x** | 잠금: 수익 훼손 방지 강화 |
| **5.2R 이상** | **1.5x** | 확정: 주도주 대세승 수확 |

### ③ 제3계: 전략 성격별 (TP1) 강제 분리
-   **주도주 (TREND, BREAKOUT, VOLUME):** **TP1 전면 폐지**. 오직 가변 트레일링과 BE 스위치로만 청산하여 "Let Profit Run" 원칙을 극단적으로 준수.
-   **비주도주 (REVERSAL, MIXED):** 짧은 호흡 유지. **2.0R** 도달 시 절반(TP1) 익절하여 기회비용 확보.

### ④ 제4계: 스마트 시간 청산 2.0 (Smart Time Exit)
시간이 초과되어도 추세와 수익이 살아있으면 생존을 허용합니다.
-   **연장 조건:** `PnL > 0` AND `Price > MA20` AND `MA20_Slope > 0` AND **`Current_R > 0.5`**
-   **작동:** 위 조건 충족 시 기존 시간 제한(`time_limit`)을 **2배**로 연장.

---

## 4. 실전 방어용 3중 레이어 (3-Layer Safety Pins)

*   **L1: Warmup Guard:** 진입 초기 2봉(10분) 동안은 일반적인 노이즈에 의한 손절을 유예합니다. (휩소 방지)
*   **L2: Doomsday SL (-4%):** 웜업 기간 중이라도 진입가 대비 -4% 하락 시 묻지도 따지지도 않고 즉각 매도하는 절대 방어선입니다.
*   **L3: Tick-Level Guard:** 5분봉 완성을 기다리지 않고, 1초 단위 틱 데이터에서 Doomsday 가격을 터치하는 순간 즉시 청산합니다. (V20.9 5분latency 공백 해결)
*   **Panic Shield (MA240 Priority):** 가격이 MA240 아래로 내려갈 경우, 비대칭 트레일링 배수를 무시하고 **1.0x**로 강제 고정하여 자본을 최우선 보호합니다.

---

## 5. 결론 및 기대 성과
V22.1 엔진은 승률(Win Rate)보다는 **손익비(Reward-to-Risk Ratio)**를 극대화하는 상위 1% 퀀트 알고리즘으로 완성되었습니다. `initial_sl` 영속화와 R-Multiple 엔진의 실구현을 통해 이제 시스템은 설계된 대로 "작게 지고 크게 먹는" 구조적 비대칭성을 실현합니다.
