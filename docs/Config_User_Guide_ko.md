# NoCodeQuant 시스템 설정(Config) 가이드 [V27.10]

> **"시스템의 성격을 정의하는 것은 숫자입니다."**
> 이 가이드는 `config.py`와 UI 설정을 통해 NoCodeQuant의 전략 성향을 튜닝하고 안전하게 운용하는 방법을 설명합니다.

---

## 1. 설정 구조 및 원칙

NoCodeQuant의 설정은 크게 세 가지 계층으로 관리됩니다.

1.  **Static Config (`config.py`)**: 시스템 경로, 기본 엔진 모드, UI 리프레시율 등 핵심 인프라 설정.
2.  **Runtime Config (`runtime_config.py`)**: 지표 기간, 이동평균선 설정 등 실시간으로 변경 가능한 전략 파라미터.
3.  **UI Settings (Dashboard)**: 사용자가 대시보드에서 직접 조정하는 스핀박스(SpinBox) 값들.

> 💡 **중요**: 대시보드에서 수정된 값은 즉시 `runtime_config`에 반영되어 전략 연산에 사용됩니다.
> 🔄 **기본 설정**: 프로그램 시작 시 **5분봉**과 **'💎 전문 스캘퍼'** 프리셋이 기본으로 로드됩니다.

## 1.1 변경 승인 등급 (Change Classification)

NoCodeQuant는 시스템의 안정성을 위해 모든 변경 작업을 네 단계로 분류하여 관리합니다. 작업 전 본인이 수행하려는 변경의 등급을 확인하십시오.

| 등급 | 이름 | 설명 | 요구 사항 |
| :--- | :--- | :--- | :--- |
| **L1** | **UI/UX** | 버튼 색상, 문구, 단순 레이아웃 수정 | 자율 수정 |
| **L2** | **Parameter** | `config.py`의 수치 튜닝, 지표 기간 조정 | 변경 리스트 기록 |
| **L3** | **Logic** | 전략 판단 로직, 주문 집행 로직 수정 | **사전 설계안(Design Note) 필수** |
| **L4** | **Architecture** | 데이터 흐름, DB 스키마, 헌장 개정 | **승인 및 마이그레이션 전략 필수** |

> ⚠️ **주의**: L3 및 L4 등급의 변경은 시스템의 '심장'을 건드리는 작업입니다. AI에게 작업을 요청할 때 반드시 [Design Note]를 동반해야 하며, AI가 거부권을 행사할 수 있습니다.

## 2. 전략 튜닝 가이드 (Strategy Tuning)

### A. 지표 파라미터 (Indicators)
지표의 기간을 조절하여 시스템의 '호흡'을 결정합니다.

| 항목 | 기본값 | 설명 | 튜닝 가이드 |
| :--- | :--- | :--- | :--- |
| `MA_SHORT` | **7** | 단기 이동평균선 | **낮을수록 민감.** 급변동에 빠르게 반응하지만 노이즈에 취약할 수 있음. |
| `MA_LONG` | **21** | 장기 이동평균선 | **장기 추세의 기준.** 골든/데드크로스의 신뢰도를 결정. |
| `RSI_PERIOD` | **14** | 심리 지수 기간 | 과매수/과매도 판단의 속도를 결정. |
| `BB_PERIOD` | **20** | 변동성 밴드 기간 | **낮을수록 밴드가 좁아짐.** 돌파 신호가 더 자주 발생. (V27.0 기본값 20) |

### B. 가이딩 엔진 (Probabilistic Engine)
산출된 지표를 어떻게 '점수'화하고 필터링할지 결정합니다.

| 항목 | 기본값 | 설명 | 해석 |
| :--- | :--- | :--- | :--- |
| `ENTRY_THRESHOLD` | **49~64** | 진입 임계값 | 국면별 기본값(TREND: 49, RANGE: 57, CHAOS: 64, DOWNTREND: 59)과 전략별 기본값(Breakout/Volume/Trend/Reversal/Mixed 모두 62) 중 더 큰(엄격한) 값을 선택 적용합니다. |
| `STB_EMA_ALPHA` | **0.1** | 안정성 민감도 | 점수 변화가 급격할 때 안정성 점수를 깎는 속도 조절. |

### C. [V27.0] 국면 가변 관리 (Institutional Regime)
시장 환경에 맞게 전략의 색깔을 자동으로 바꿉니다.

| 항목 | 값 | 설명 |
| :--- | :--- | :--- |
| **ADX Hysteresis**| **22-25** | ADX 25 돌파 시 `TREND`(추세), 22 붕괴 시 `RANGE`(박스)로 판단. (+5/-5 밴드 히스테리시스 포함) |
| **Hysteresis 효과**| **노이즈 제거**| 잦은 국면 전환(Chattering)을 방지하여 매매 안정성 확보. |
| **VSA Confirmation**| **Dual-Filter** | `WEAK_VSA` 패널티(volume_ratio < 0.8x일 때 감점)와 VOLUME 전략형 하드 필터(volume_ratio < 1.5x일 때 진입 차단)의 이중 구조로 수급을 필터링합니다. 음봉은 0점 처리됩니다. |

### C. 시장 열기 지표 (Smart Heat Index)
키움 [0198] 조회를 대체하는 통합 주도주 선별 엔진입니다.

| 항목 | 설명 | 활용 팁 |
| :--- | :--- | :--- |
| **Heat Score** | 0.0 ~ 1.0 점수 | **0.65 이상**이면 시장 주도주로 판단. AI 전략의 가중치로 활용됨. |
| **ETF/ETN 필터** | 파생상품 원천 배제 | 순수 개별 주동주에만 집중하여 지수의 순수성 확보. |
| **Lightning Filter**| 폭락주(-7%) 차단 | 급략 중인 종목은 거래대금이 많아도 주도주에서 즉각 제외. |

### D. [V27.0] AI 도슨트 (AI Docent UI)
엔진의 복잡한 속마음을 시각적 아이콘과 툴팁으로 설명합니다.

- **페널티 아이콘**: `🐻` (글로벌 베어), `⚠️` (수급 미달 / WEAK_VSA) 아이콘이 대시보드에 표시됩니다.
- **국면 모니터**: 우측 하단 패널(Theme Flow 및 보유잔고 독립 독위젯)에서 현재 국면, 수급 상태, HTF 트렌드를 한눈에 확인 가능합니다.
- **AI 종합 분석**: 단순 수치 요약이 아닌 지표 간의 인과관계와 향후 시나리오를 제시합니다.

## 3. 리스크 관리 (Risk Management)

| 항목 | 설명 | 설정 방법 |
| :--- | :--- | :--- |
| **Stop Loss** | 개별 종목의 손절 라인 | UI에서 `%` 단위로 설정. (기본 3.0%) |
| **Kill Switch** | 당일 최대 손실 제한 | 예수금 대비 전체 손실 비율 도달 시 매매 중단. |
| **TimeGate** | 장 막판 매매 제한 | **15:00 이후** 신규 매수 신호를 차단하여 오버나이트 리스크 방어. |
| **HedgeGate** | 장 마감 강제 청산 | **15:10 기준** 수익률 -2.0% 미만 약세 종목 즉각 청산. |
| **GapGuard** | 시가 갭 보호 | 시가 -5% 이내 하락 시 **30초간 손절 유예**. |
| **Pending Timeout [V20.9.3]** | Pending 영구 잠금 방어 | 체결 콜백 크래시 등으로 주문 Pending이 풀리지 않을 때 **30초 후 강제 해제**. |
| **VWAP Guard [V23.3]** | 체결단가 오염 방어 | 청산 체결 평균가가 진입가 대비 50% 이상 괴리 시 최신 호가 또는 진입가로 자동 보정. |
| **매매 빈도 제한** | 하루 최대 매매 횟수 설정 | 체크박스로 기능을 켜고 끌 수 있으며, 과도한 수수료 발생을 방지함. |
| **Mock Mode** | 가상 매매 모드 | 실제 주문 전 전략 검증을 위해 반드시 활성화 권장. |

## 4. 운영 팁 (Operational Tips)

### "매매가 너무 안 일어나요"
1. `ENTRY_THRESHOLD`를 낮추어 보십시오.
2. `MIN_CONFIDENCE`를 30%에서 **20%**로 낮추어 지표 신호를 더 신뢰하십시오.
3. `BB_PERIOD`를 줄여 변동성 밴드를 타이트하게 만드십시오.

### "가짜 신호(Whipsaw)에 자꾸 속아요"
1. `MA_LONG`을 21에서 **40** 이상으로 늘려 더 긴 추세를 보십시오.
2. `MIN_CONFIDENCE`를 **40% 이상**으로 높여 시장 안정성을 더 엄격히 따지십시오.
3. 타임프레임을 1분봉에서 **5분봉/15분봉**으로 늘리십시오.

### "매수/매도 시그널만 보고 싶어요" (엔진 정지 분석)
- **Engine Toggle**: `🛑 엔진 정지 (PAUSED)` 상태에서도 실시간 차트 분석과 의사결정 허브는 계속 업데이트됩니다. 주문 집행 없이 전략의 유의성을 테스트하고 싶을 때 활용하십시오.

### "다른 주기의 봉을 참고용으로 따로 보고 싶어요" (멀티차트 활용)
- **🖥️ 멀티차트**: 본 차트 분봉 레이블 우측에 위치한 "멀티차트" 버튼을 통해 독립된 팝업 창을 띄울 수 있습니다.
  - 본 차트에서 종목이 바뀌면 멀티차트의 종목도 연동되어 갱신됩니다.
  - 멀티차트 팝업 내에서 일/주/월/분봉을 개별 조작하는 것은 메인 시스템(전략 실행, 의사결정허브)의 타임프레임 상태에 영향을 미치지 않도록 **제어가 격리**되어 있으므로, 편하게 백테스팅 및 국면 참고용으로 교차 검증하실 수 있습니다.

### "AI 종합 분석 결과를 읽고 있는 중에 자꾸 체크리스트 화면으로 리셋돼요"
- **AI 분석 결과 화면 잠금 및 가로 래핑 가독성 개선**: AI 분석 결과를 요청해 GPT 분석 보고서가 로딩되면, 실시간 틱 수신 등으로 화면이 자동 갱신되더라도 분석 뷰가 유지(Lock)되도록 개선되었습니다.
  - 보고서를 다 읽으신 후 버튼 영역에 활성화되는 **`"↩️ 돌아가기 (AI 분석 종료)"`** 버튼을 클릭하시면, 실시간 틱 수급 조건 체크리스트 화면으로 안전하게 복귀할 수 있습니다.
  - 또한, 창 너비에 맞춰 분석 텍스트가 조기에 개행되지 않고 가로 영역 전체를 온전히 활용하도록 래핑 최적화 및 창 크기 변경 시 반응형 레이아웃 재연산이 탑재되어 더욱 우수한 가독성을 선사합니다.
  - **레이아웃 안정성 유지**: 텍스트가 팽창할 때 전체 UI 레이아웃이 붕괴되는 것을 막기 위해 AI Insight 뷰어의 세로 크기를 130px로 고정하였으며, 넘치는 텍스트는 얇고 모던한 다크 테마용 마이크로 스크롤바(6px)를 이용해 부드럽게 스크롤하여 읽으실 수 있습니다.
