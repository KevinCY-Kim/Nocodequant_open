### 2.2 Forensic UI 2.0 고도화
*   **가동성**: 9개 컬럼(`ID`, `시간`, `종목명`, `구분`, `점수`, `수량`, `가격`, `수익`, `주문근거`)으로 확장된 감사 트레일 구현.
*   **ID 체계**: `HHMMSS-Side` 형식의 가독성 높은 ID 적용. -> **[2026-02-11 업데이트]** 24자 풀 포맷 GTID(`YYYYMMDD-HHMMSS-STRAT-UUID6`)로 격상되어 글로벌 고유성 확보.
*   **UX 디자인**: 테이블 전체 **가운데 정렬(Center Align)** 및 헤더별 정렬 기능 활성화.
*   **실시간 정렬 유지**: 새로운 로그가 삽입되어도 정렬 상태(최신순)를 자동으로 유지하도록 `append_log_event` 로직 개선.
*   **이름 변환**: 로그인 후 종목 코드를 실시간으로 종목명으로 변환하는 자동 갱신 기능 추가.
