## [V16.0 Stability Patch] DB Lock & UI IndexError 완벽 해결 (L4/L5)
- **목표**: 대용량 WAL(500MB+) 환경에서 `ATTACH` 마이그레이션 실패(`database is locked`) 및 UI 집계 오류 해결.
- **주요 변경**:
    - **Batch Record Copy (100% 신뢰)**: 잠금 경합이 심한 `ATTACH` 대신, 독립된 두 커넥션을 활용한 **500행 단위 배치 복사** 로직으로 마이그레이션 방식 전면 교체.
    - **99.9% 용량 다이어트**: 이전 완료 후 `trades.db`에서 시그널 테이블 적출 및 `VACUUM` 수행 → **535MB → 90KB**로 축소 성공.
    - **IndexError 방지**: `ForensicDashboard`의 데이터 모델 리셋 시 집계 상태(`last_event_row` 등)를 즉시 초기화하여 런타임 에러 차단.
    - **엄격한 싱글턴**: `PersistenceManager`에 프로세스 레벨 락(Lock)을 적용하여 `TradeLogger` 등 멀티 모듈에서의 중복 점유를 원천 봉쇄.
- **결과**: 331,566행의 거대 로그 환경에서도 100% 성공률의 구동 및 수 밀리초 단위의 대시보드 로딩 성능 확보.
