# 2026-04-04 작업일지 (Work Log)

## [V20.2] AI 전략 튜닝 - 관측성(Observability) 및 롤백(Rollback) 구현 (L4)
- **목표**: 튜닝의 적용 상태를 실시간으로 시각화하고, 잘못된 적용에 대비한 즉각적인 원복(Rollback) 경로를 제공하여 시스템 통제권 강화.
- **주요 변경**:
    - **상태 관리 레이어(`ActiveTuningState`) 구축**:
        - `TuningCoordinator` 내부에 독립적인 `TuneRecord` 레지스트리 신설.
        - `QUEUED`(대기), `ACTIVE`(적용됨), `ROLLED_BACK`(원복됨)의 3단계 상태 머신(State Machine)을 통해 튜닝 생애주기 관리.
        - 적용 직전의 `original_val`을 캡처하여 데이터 무결성이 보장된 롤백 기반 마련.
    - **UI 관측성 혁신 (`strategy_dashboard.py`)**:
        - **상태 뱃지 시스템**: 각 전략 카드 상단에 현재 튜닝 상태를 나타내는 색상 뱃지 도입.
            - 🟢 **TUNED**: 파라미터가 수정되어 운용 중 (변경 수치 및 시간 표시).
            - 🟡 **QUEUED**: 포지션 청산 후 자동 적용 대기 중.
            - ⚙️ **ORIGINAL**: 기본 설정 상태.
        - **[↩ 원복] 버튼**: `ACTIVE` 상태인 경우에만 노출되며, 클릭 시 시스템을 0.1초 만에 튜닝 전 상태로 복구.
    - **반응형 리렌더링 (Reactive UI)**:
        - 버튼 클릭 시 `refresh_data()`를 호출하여 UI를 통째로 다시 그리는 전략을 통해 PyQt의 한계를 극복하고 즉각적인 조작감(타격감) 제공.
    - **거버넌스 강화**:
        - 롤백 발생 시 `forensics.db`에 `TUNE_ROLLED_BACK` 이벤트를 기록하여 감사 추적성(Audit Trail) 확보.
- **최종 결과**:
    - "AI가 무엇을 바꿨고, 어떻게 되돌릴 수 있는가?"에 대한 답을 UI로 명확히 제시.
    - 관측성 부재로 인한 심리적 불안 요소를 제거하고, 100% 통제 가능한 자동화 환경 구축.

## [V20.8] 전략별 포커스 모드 (Strategy Focus Mode) 및 데이터 무결성 하드닝
- **목표**: 통합 대시보드에서 발생하는 전략 간 성과 상쇄(Cancellation Effect)를 방지하고, 특정 전략(TREND, REVERSAL 등)만 핀포인트로 분석할 수 있는 기관급 의사결정 환경 구축.
- **주요 변경**:
    - **전략별 독립 분석 엔진 (Strategy-Specific Filtering)**:
        - `UPPER()` 정규화를 포함한 SQL 필터링 로직을 `PersistenceManager` 레벨에 이식.
        - "전체" 포트폴리오 뷰와 개별 전략 뷰 간의 데이터 전환 시 0.1초 이내의 응답성 확보.
    - **데이터 무결성 (Integrity) 하드닝**:
        - **DB-Level Aggregation**: 모든 KPI(총거래, 승률, PnL)를 사이드 이펙트가 없는 SQL `SUM/COUNT` 집계로 강제하여 필터링 시에도 1원 한 장 틀리지 않는 정확도 보장.
        - **캐시 충돌 방지**: 캐시 키에 `query_type`을 도입하여 KPI, 요약, 로그 데이터 간의 충돌(Collision)을 원천 차단.
    - **Log-to-KPI 동기화**:
        - `get_recent_trades` 수행 시 전체 데이터 개수(`total_count`)를 함께 반환.
        - 로그 탭 하단에 `총 {Y}건 중 최근 {X}건 표시` 상태바를 추가하여 UI 수치 불일치로 인한 오해 방지.
- **최종 결과**:
    - 전략 튜닝의 효과를 개별 전략 단위로 현미경 분석할 수 있는 정밀 타격 환경 완성.

## [V20.8.1] KPI 폴리싱 (KPI Polish) - 시각적 소음 제거 및 신뢰도 최적화
- **목표**: 150건 이상의 신뢰도 높은 샘플에서도 "LOW CONFIDENCE" 경고가 남발되던 현상을 수정하고, 시각적 소음을 70% 이상 제거하여 전문 분석 도구로서의 품격 강화.
- **주요 변경**:
    - **신뢰도 지표 중앙화 (Centralized Confidence)**:
        - 6개 KPI 카드마다 반복되던 `n=xxx` 정보와 신뢰도 뱃지를 **[총 거래 수]** 카드로 단일화.
        - 나머지 카드들은 핵심 지표와 델타(🔼/🔽)에만 집중하도록 설계하여 시각적 과부하 제거.
    - **통계적 신뢰도 임계값(Threshold) 현실화**:
        - **HIGH**: n >= 100 (기존 50)
        - **MED**: n >= 30 (기존 20)
        - **LOW**: n < 30 (기존 20)
        - n=158과 같은 충분한 샘플에서 `HIGH CONFIDENCE (Green)`가 정상 출력되도록 보정.
    - **글로벌 신뢰도 배너**:
        - 상단 메인 배너의 `refresh_data` 완료 시점에 실제 로드된 샘플 수와 신뢰 상태를 한 줄로 요약 표기하여 상황 인지 능력(Situational Awareness) 극대화.
- **최종 결과**:
    - 데이터가 톱니바퀴처럼 딱딱 맞물려 돌아가는 "기관급 UI"의 미학적 완성도 확보.
