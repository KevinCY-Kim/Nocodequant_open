### 6. [V23.3] 주도주(HOT) 랭킹 엔진 치명적 버그 수정
- **문제 진단**: 상한가 진입 종목, 우선주, 저유동성 종목이 실시간 감시 리스트 상위에 노출되어 감시 슬롯 낭비 및 매매 기회비용 발생.
- **근본 원인**: 
  - 데이터 소스가 '당일 누적'(키움 TR) 기준 → 오전 폭발 후 멈춘 종목도 1위 유지.
  - `liq_quality` 버그: 거래대금 데이터 없는 종목에 0.5(50% 보존) 특혜 부여.
  - 모멘텀 점수: 3%~12% 구간을 모두 만점(1.0)으로 획일화 + 상한가(+30%)에도 0.2점 부여.
- **수정 내역** (`ranking_manager.py`):
  - 우선주 `EXCLUDE` 필터 추가 (종목명 '우/우B/우C' 패턴).
  - **상한가(+29%) `EXCLUDE`** 필터 추가 → 매수 불가 종목 감시 원천 차단.
  - **거래대금 게이트**: VALUE 리스트 미등재 종목 점수 85% 삭감.
  - `liq_quality` 버그 수정: 거래대금 없음 시 0.5 → 0.1 페널티.
  - **모멘텀 선형 비례화**: 계단식 → 선형 비례 + 20% 초과 = 0점 처리.

### 8. [V23.3 Phase1] 실시간 생존 검증 필터 구현
- **위치**: `ranking_manager.py` → `_calc_alive_factor()`
- **메커니즘**: `RealtimeQuote.timestamp` 기준으로 마지막 체결 이후 경과 시간에 따라 0.05~1.0 감쇄 계수 적용.

### 9. [V23.3 Phase2] 자체 모멘텀/급등세 엔진 구현
- **위치**: `ranking_manager.py` → `update_quote_snapshot()`, `_calc_realtime_momentum()`, `_calc_realtime_surge()`

- **자체 모멘텀**: 최근 15분 가격 변화율 기반 (0.0~1.0)
- **자체 급등세**: 최근 5분 거래량 vs 이전 20분 평균 비율 기반 (0.0~1.0)
- **블렌딩**: 기존 TR 기반 점수(mom_norm, acc_norm)와 자체 계산값을 **50:50 블렌딩**하여 점진적 전환.
- **Graceful Fallback**: 데이터 부족 시(None 반환) 기존 TR 점수 100% 유지.

### 10. [V23.3 FIX] 체결가(Exit Price) 오염 버그 수정
- **증상**: 성창기업지주(000180) 수동 매도 시 청산가가 191원(진입가 7,390원 대비 -96.75%)으로 기록.
- **근본 원인**: 저유동성 종목에서 HTS 매도/취소 반복 시, 키움 Chejan FID 910(체결가)에 부호 포함 값 또는 비정상 값이 유입되어 VWAP(price_sum/cum_qty) 계산을 오염.
- **수정 (3중 방어)**:
  1. **engine.py**: Chejan 체결가에 `abs()` 적용 + `price<=0 or qty<=0` Sanity Guard (비정상 데이터 원천 차단).
  2. **order_manager.py (is_position_closed)**: VWAP Sanity Guard — exit_price가 entry_price 대비 50% 이상 괴리 시 현재 시가로 보정.
  3. **order_manager.py (flush_sell_accumulators)**: 동일 Guard를 종료 시 강제 플러시 경로에도 적용.

### 11. [V23.3 FIX] 랭킹 엔진 안정성 및 무결성 강화
- **HOT2 가속지수 부호 오류 수정**: 음의 가속도(급락)가 절대값 처리되어 HOT2에 진입하던 역설을 해결. `accel > 0` 및 `chg >= 0` 가드를 통해 상승 가속 종목만 추출.
- **UI 데이터 라우팅 정상화**: "거래대금/거래량" 탭이 필터링되지 않은 raw 데이터를 직접 참조하던 경로를 차단하고, `RankingManager`의 정제된(filtered) 데이터를 경유하도록 수정.
- **[Critical] 랭킹 감쇄 누수(Leak) 차단**: 마이너스 종목의 점수를 깎는 `damping` 계수가 계산만 되고 실제 점수 합산에 곱해지지 않던 치명적 결함을 수정. 이제 `-3% ~ 0%` 구간의 투매 종목은 지수적으로 급격한 점수 삭감을 받아 상위권 진입이 원천 차단됨.
- **급락주 차단 강화**: `EXCLUDE` 임계값을 `-7%`에서 `-3%`로 대폭 상향하여 하락 추세 종목의 감시 리스트 점유를 방어.

### 12. [V23.5] Authority Graph 기반 테마 무결성 강화 및 할루시네이션 차단
- **문제 진단**: 키움 API의 '금융' 섹터 분류가 광범위하여, DSC/TS인베스트먼트(창투사) 등 테마 정보가 누락된 종목이 2-hop 추론 시 '제과스낵' 등 섹터 내 노이즈 테마로 오매칭되는 현상(할루시네이션) 확인.
- **해결 (Authority Layer 도입)**:
    - **KRX 마스터 데이터 통합**: KIND 상장법인목록 기반 `krx_master.json` 구축 (2,767종목). 전 종목에 KRX 공식 업종 분류 주입.
    - **Subsector 정교화**: KRX의 162개 세부 업종명을 `subsector`로 직접 할당하여 피어 그룹 범위를 획기적으로 축소 (예: 금융 -> 신탁업 및 집합투자업).
    - **Confidence(신뢰도) 시스템**: `theme_confidence` 필드를 도입하여 KRX 확인 데이터(1.0)와 키움 데이터(0.5) 구분. 신뢰도가 0.0(부재)인 경우에만 2-hop 추론 허용.
    - **추론 로직 고도화**: 테마 누락 종목 추론 시, 섹터 전체가 아닌 동일 `subsector` 피어들만 샘플링하여 업종 내 노이즈 완벽 차단.
- **UI 피드백 강화**: 추론 결과에 `(추론)` 접미사를 추가하여 데이터의 신뢰도 수준을 사용자에게 가시화.
- **호환성 유지**: 구버전 캐시 로드 시에도 자동으로 KRX 데이터를 재병합하는 자동 보정 로직 적용.
