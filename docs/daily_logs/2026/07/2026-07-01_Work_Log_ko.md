## ✅ 상세 작업 및 패치 내역

### 1. `opt10077` 연속조회 및 누적 합산 로직 구현
- **engine.py (`on_receive_real_data`/`_parse_opt10077`)**:
  - 페이지 단위로 수신되는 개별 손익 상세 데이터를 모으기 위해 클래스 내 임시 인스턴스 누적기(`_pnl_accum_sum`, `_pnl_accum_details` 등) 신설.
  - 서버 응답의 `prev_next` 속성값이 `'2'`(연속 데이터 존재)인 경우, 200ms 주기의 TR 요청 큐(`_enqueue_tr`)에 연속조회를 자동으로 재등록(API 조회 과부하 방어 목적).
  - 더 이상 연속 데이터가 없을 때(`prev_next`가 `'0'`이거나 공백) 누적된 실현손익 최종 합계를 `sig_realized_pnl` 시그널로 단 1회만 내보내도록 수정하여 불필요한 이벤트 중복 전파 방지.
  - 연속 조회가 무한루프에 빠질 위험을 방어하기 위해 페이지 상한선 `_PNL_MAX_PAGES = 50` 가드 장치 추가.
  - `prev_next`의 기본값을 `'0'`으로 설정하여 연속 조회가 필요 없는 기존 시나리오들과의 하위호환성 유지.
